人民币金额大小写转换规范标准
依据：中国人民银行《支付结算办法》（银发〔1997〕393号）附一《正确填写票据和结算凭证的基本规定》

一、基础字符对照表
阿拉伯数字→中文大写：
0→零  1→壹  2→贰  3→叁  4→肆  5→伍  6→陆  7→柒  8→捌  9→玖
单位字符：
元(基本单位)  角(1/10元)  分(1/100元)  拾  佰  仟  万  亿  整/正(结束标记)  人民币(币种标识)

禁止使用：一、二(两)、三、四、五、六、七、八、九、十、念、毛、另、0等简化字或替代字

二、核心书写规则
【格式规范】
1. 字体：必须使用正楷或行书填写，字迹清晰、不易涂改
2. 币种标识：大写金额前必须标明"人民币"字样，且紧接填写，不得留空
3. 结束标记：
    - 到"元"为止：元后写"整"或"正"字
    - 到"角"为止：角后可写可不写"整/正"
    - 有"分"的：分后不得写"整/正"

【"零"的处理规则】
1. 数字中间有单个0：写一个"零"字
   例：￥1,409.50 → 人民币壹仟肆佰零玖元伍角
2. 连续多个0：只写一个"零"
   例：￥6,007.14 → 人民币陆仟零柒元壹角肆分
3. 万位/元位是0，但千位/角位非0：可写一个"零"，也可不写
   例：￥1,680.32 → 人民币壹仟陆佰捌拾元零叁角贰分 或 人民币壹仟陆佰捌拾元叁角贰分
4. 角位是0，分位非0："元"后必须写"零"
   例：￥325.04 → 人民币叁佰贰拾伍元零肆分

记忆口诀：角零分非零，元后必加零；万零千非零，零字可省略

【小写金额规范】
1. 阿拉伯数字前必须填写人民币符号"￥"
2. 数字应逐个书写，不得连写导致分辨不清
3. 金额精确到"分"，小数点后保留两位

三、日期大写规范（票据专用）
出票日期必须使用中文大写，防止变造：

【月份规则】
- 1、2、10月：前加"零" → 零壹月、零贰月、零壹拾月
- 3-9、11-12月：正常大写 → 叁月、壹拾壹月

【日期规则】
- 1-9、10、20、30日：前加"零" → 零壹日、零贰拾日
- 11-19日：前加"壹" → 壹拾伍日

示例：2026年3月19日 → 贰零贰陆年零叁月壹拾玖日

四、禁止事项清单
❌ 不得预印固定单位：票据大写栏内不得预印"仟、佰、拾、万、元、角、分"等固定字样
❌ 不得自造简化字：如"两"代"贰"、"毛"代"角"等
❌ 不得混用大小写：同一金额不得同时出现"100元"和"壹佰元"混合写法
❌ 不得涂改：金额、日期、收款人名称不得更改，更改则票据无效
❌ 不得使用繁体字替代：虽可受理，但建议统一使用标准简体大写

五、完整转换示例
￥100.00      → 人民币壹佰元整
￥100.50      → 人民币壹佰元伍角
￥100.55      → 人民币壹佰元伍角伍分
￥1,008.00    → 人民币壹仟零捌元整
￥10,008.00   → 人民币壹万零捌元整
￥100,000.50  → 人民币壹拾万元零伍角
￥1,000.05    → 人民币壹仟元零伍分

六、程序实现建议（开发参考）
核心逻辑要点：
1. 金额×100转为整数处理，避免浮点精度问题
2. 按"亿-万-元-角-分"分段处理，每段内按"仟佰拾"处理
3. 零的处理：连续零合并、末尾零省略、角零分非零补零
4. 单位添加：非零数字后加对应单位，整元/角加"整"
5. 边界校验：金额范围、负数处理、超长数字截断

推荐测试用例：0.01、100.00、1001.05、10000.00、100000.10、999999999.99

七、常见错误对照
错误写法                    正确写法                    错误原因
人民币 壹佰元整    →    人民币壹佰元整    "人民币"后留空
壹佰元            →    人民币壹佰元整    缺少币种标识和"整"字
壹仟零佰零拾元整  →    壹仟元整          冗余单位，应省略零位单位
壹仟元零角零分整  →    壹仟元整          无角分不应写"零角零分"
1月5日→一月五日   →    零壹月零伍日      日期未用大写且未防变造

法律效力提示：
票据和结算凭证中，中文大写与阿拉伯数码记载的金额必须一致，二者不一致的票据无效，银行不予受理。

适用范围：
银行票据、财务凭证、合同金额、发票填写、司法文书等所有涉及人民币金额的正式场景。

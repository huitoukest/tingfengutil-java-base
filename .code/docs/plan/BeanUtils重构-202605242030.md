## 2. 详细类设计

### 2.1 `BeanDesc` — 属性描述缓存

**位置**：`bean/copier/BeanDesc.java`（NEW）
**定位**：内部辅助类，包级可见（非 public），对外通过 BeanCopier 间接使用

**设计思路**：
- 对每个 `Class<?>` 仅内省一次，结果缓存于 `SimpleCacheHelper`
- 自动检测模式：优先使用 `PropertyDescriptor`（getter/setter），不存在则降级 `Field`
- 提供统一的 `getPropertyValue(bean, name)` / `setPropertyValue(bean, name, value)` 方法

**成员与 API**：

```java
// 包级可见，不对外暴露
class BeanDesc {
    private final Class<?> beanClass;
    private final Map<String, PropertyDescriptor> pdMap;    // 有 getter/setter 的属性
    private final Map<String, Field> fieldMap;               // 所有属性（含私有）

    BeanDesc(Class<?> beanClass);

    Class<?> getBeanClass();
    
    // 获取可读属性名集合（pdMap + fieldMap 的并集）
    Set<String> getPropertyNames();
    
    // 获取可读属性值（先 pdMap.getReadMethod，无则 field）
    Object getPropertyValue(Object bean, String name);
    
    // 设置属性值（先 pdMap.getWriteMethod，无则 field）
    void setPropertyValue(Object bean, String name, Object value);
    
    // 是否有 PropertyDescriptor（即符合 JavaBean 规范）
    boolean hasPropertyDescriptor(String name);
}
```

**边界条件**：
- `getClass` 属性应自动过滤（Introspector 自带）
- `fieldMap` 应排除 `static` / `final` 字段
- 当 `--add-opens` 未开启时，`Field.setAccessible` 可能抛异常 → 静默跳过该字段

### 2.2 `CopyOptions` — 拷贝配置选项

**位置**：`bean/copier/CopyOptions.java`（NEW）
**定位**：配置 POJO，链式 setter 风格

**API 设计**：

public class CopyOptions {

### 2.3 `BeanCopier` — 拷贝执行引擎

**位置**：`bean/copier/BeanCopier.java`（NEW）
**定位**：核心引擎，使用 `SimpleCacheHelper` 缓存 `BeanDesc`，供 `BeanUtil` 及 `ValueProvider` 使用

**缓存设计**：
- 使用已有 `SimpleCacheHelper`，容量 512
- Key：`UnionKey(sourceClass, targetClass)` 或仅 `beanClass`（单类操作如 toMap）
- Value：对应 beanClass 的 `BeanDesc`
- 不对 `(sourceClass, targetClass, CopyOptions)` 的组合进行缓存 → 因 `CopyOptions` 可变，每次创建新 `BeanCopier` 实例更安全

**API 设计**：

```java
package com.tingfeng.util.java.base.bean.copier;

// public 但建议仅由 BeanUtil 调用
public class BeanCopier {
    
    // ========== 缓存 ==========
    private static final SimpleCacheHelper<UnionKey, BeanDesc> SOURCE_DESC_CACHE = new SimpleCacheHelper<>(512);
    private static final SimpleCacheHelper<UnionKey, BeanDesc> TARGET_DESC_CACHE = new SimpleCacheHelper<>(512);

    // ========== 核心拷贝 ==========
    
    /**
     * 拷贝属性：source → target
     * @param source 源对象
     * @param target 目标对象
     * @param options 配置选项，null 时使用默认
     */
    public static void copy(Object source, Object target, CopyOptions options);
    
    /**
     * 从 ValueProvider 拷贝到 Bean
     * @param provider 值提供者
     * @param target 目标对象
     * @param options 配置选项
     */
    public static void copyFromProvider(ValueProvider provider, Object target, CopyOptions options);
    
    /**
     * Bean → Map (String, Object)
     * @param bean 源 Bean
     * @param options 配置选项
     * @param ignoreFields 忽略的字段名
     * @return Map 包含所有非 null 的非忽略属性
     */
    public static Map<String, Object> toMap(Object bean, CopyOptions options, String... ignoreFields);
}
```

**核心逻辑（伪代码）**：

```
copy(source, target, options):
  if source == null || target == null: return
  sourceClass = source.getClass()
  targetClass = target.getClass()
  sourceDesc = getOrCreateBeanDesc(sourceClass)
  targetDesc = getOrCreateBeanDesc(targetClass)
  
  // 获取 target 的可写属性名
  targetProps = options.forceFieldAccess ? targetDesc.fieldMap.keySet() 
                                         : targetDesc.getWritablePropertyNames()
  
  for each propName in targetProps:
    // 1. 检查忽略列表
    if options.ignoreProperties contains propName: continue
    
    // 2. 字段映射
    sourceFieldName = options.fieldMapping?.getOrDefault(propName, propName)
    
    // 3. 从 source 取值
    if sourceFieldName not in sourceDesc.getPropertyNames(): continue
    value = sourceDesc.getPropertyValue(source, sourceFieldName)
    
    // 4. 忽略 null
    if value == null && options.ignoreNull: continue
    
    // 5. 类型转换（跨类型时）
    targetType = targetDesc.getPropertyType(propName)
    if value != null && value.getClass() != targetType && options.useConverter:
      value = ConverterRegistry.getInstance().convert(value, targetType, value)
    
    // 6. 赋值
    targetDesc.setPropertyValue(target, propName, value)
```

**模式自动检测**：
- 默认：遍历 target 属性时，先尝试 `targetDesc.pdMap`（PropertyDescriptor），该属性存在 getter/setter 则用，否则降级 `targetDesc.fieldMap`
- `forceFieldAccess=true`：跳过 PropertyDescriptor，直接使用 Field

### 2.7 `BeanUtils` — 向后兼容层（修改）

**位置**：`bean/BeanUtils.java`（MODIFY）

**修改策略**：
1. 类级别添加 `@Deprecated` 注解 + Javadoc 提示迁移到 `BeanUtil`
2. 每个 public 方法添加 `@Deprecated` 注解
3. 方法体内部委托到 `BeanUtil`（或 `BeanCopier`）新实现
4. 保留以下方法（标记 @Deprecated）：
   - `copyProperties(Object, Object, String...)` → 委托 BeanUtil，exceptFields 转 CopyOptions
   - `copyProperties(Object, Object, boolean, Collection<String>)` → 委托 BeanUtil
   - `copyProperties(Object, Object, boolean, String...)` → 委托 BeanUtil
   - `copyProperties(Object, Object)` → 委托 BeanUtil
   - `copyProperties(Object, Object, Predicate, Function, String...)` → 委托 BeanUtil（通过 CopyOptions 简化）
   - `copyProperties(Object, Object, Predicate, Function, Collection<String>)` → 同上
   - `copyPropertiesNotStrict(...)` → 委托 BeanUtil (forceFieldAccess=true)
   - `copyListProperties(List, Class, String...)` → 委托 BeanUtil.toList
   - `toMap(T, PropertyFunction...)` → 委托 BeanUtil.toMap + PropertyFunction → fieldName
   - `getBeanByMap(Class, Map)` → 委托 BeanUtil.toBean(ValueProvider)
   - `getBeanByMap(T, Map)` → 委托 BeanCopier
   - `getBeanInfo(Class)` → 保留（纯代理 Introspector，无耦合）
   - `getFieldNameByGetter(String)` → 保留（纯字符串操作，无耦合）
   - `createBeanConverter(...)` → 保留现有实现或委托
   - `getBeanCopyMethodMap(...)` → 保留现有实现（或标记删除）
   - `getBeanCopyFieldMap(...)` → 保留现有实现（或标记删除）
   - `getBeanCopyFunMap(...)` → 保留现有实现（或标记删除）

**关键兼容性要求**：
- `LambdaUtils.java` 使用 `BeanUtils.getFieldNameByGetter(getter)` → 方法保留（不标记 @Deprecated）
- `CSVUtil.java` 使用 `BeanUtils.createBeanConverter(headers[0], beanCls, null)` → 方法保留（可标记 @Deprecated 但保留实现）

## 5. 状态转换表

本次无复杂状态机。以下简要列出 BeanDesc 缓存生命周期：

| 阶段 | 状态 | 说明 |
|------|------|------|
| 首次调用 | MISS → CREATE | `SimpleCacheHelper.get(key)` 返回 null → 创建 BeanDesc → set(key) |
| 后续调用 | HIT | `SimpleCacheHelper.get(key)` 直接返回 |
| 缓存满 | EVICT | LRU 策略淘汰最不常用条目 |
| JVM 重启 | CLEAR | 缓存随内存释放 |

## 6. 核心边界条件与异常处理策略

### 6.1 边界条件表

| 边界场景 | 处理策略 |
|----------|----------|
| source == null | `copyProperties`: 直接 return（不抛异常）；`toBean`: 返回 null；`toMap`: 返回 empty map |
| target == null | `copyProperties`: 直接 return；`toBean`: 抛 `IllegalArgumentException` |
| targetClass == null | `toBean` / `toList`: 抛 `IllegalArgumentException` |
| targetClass 无默认构造器 | `toBean`: 抛 `BaseException` 包装 `InstantiationException` |
| PropertyDescriptor 内省异常 | 降级到 Field 模式（静默），日志 debug 输出 |
| Field.setAccessible 被拒绝 | 跳过该属性（日志 debug），不影响其他属性 |
| source 与 target 无共同属性 | 不抛异常，拷贝结果为空对象 |
| ignoreProperties 为 null | 视为无忽略，不抛异常 |
| fieldMapping 为 null | 不启用映射，直接按属性名匹配 |
| 跨类型转换失败 | 如果 `useConverter=true` → 使用 `ConverterRegistry.convert(source, targetType, defaultValue)`；若转换失败 → 跳过该属性，不抛异常（日志 debug） |
| MapValueProvider.key 为 a.b.c 点号 | 尝试通过 `ReflectUtils` 递归获取嵌套属性值 |
| 列表批量操作时列表为 null/empty | null → 返回 emptyList；empty → 返回 emptyList |

### 6.2 异常处理策略

| 异常来源 | 处理方式 |
|----------|----------|
| `IntrospectionException` | 包装为 `BaseException` 抛出（严重，Bean 内省失败） |
| `IllegalAccessException` / `InvocationTargetException` | 包装为 `BaseException` 抛出（反射访问失败） |
| `InstantiationException` | 包装为 `BaseException` 抛出（目标类无默认构造器） |
| `ConverterException` | 属性级转换失败 → 静默跳过该属性（日志 debug） |
| 其他运行时异常 | 不捕获，正常上抛 |

## 9. 风险点与缓解措施

| 风险 | 影响 | 可能性 | 缓解措施 |
|------|------|--------|----------|
| BeanDesc 缓存 OOM | 内存溢出 | 低 | SimpleCacheHelper 自带 LRU 淘汰，容量 512 |
| `Field.setAccessible` JDK 17+ 模块系统限制 | Field 模式失效 | 中 | 捕获异常，静默跳过该属性；日志 debug 输出 |
| 大量类型转换导致 ConverterRegistry 压力 | 性能下降 | 低 | 默认 useConverter=true，瓶颈时可通过 CopyOptions 关闭 |
| BeanUtils 过多方法委托遗漏 | 兼容性问题 | 中 | 逐方法审查，覆盖所有 public 方法；单元测试验证 |
| PropertyDescriptor + Field 双模式行为不一致 | 拷贝行为差异 | 中 | 强制统一顺序：先 PropertyDescriptor 后 Field，优先级明确 |
| 缓存 key（CopyOptions）hashCode/equals 未正确实现 | 缓存错误命中 | 低 | CopyOptions 必须正确实现 equals/hashCode |
| createBeanConverter 使用 ConverterUtils（旧）冲突 | 类型转换混乱 | 低 | 保留现有实现，不与新 Converter 体系耦合 |

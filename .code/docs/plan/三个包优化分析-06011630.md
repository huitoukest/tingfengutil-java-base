## 二、模块划分

按高内聚低耦合归类为 5 个模块：

### Module 1：common/collection/ — ReadWriteArrayList 核心修复

**问题**：
- P0：iterator() 返回 `new ArrayList<>(list).iterator()` 快照副本，导致 removeIf() 失效
- P1：BaseTimeBufferConsumerCollection 线程池 Integer.MAX_VALUE 可能创建过多线程

**修复方案**：
1. 重写 removeIf(Predicate)：直接在写锁下遍历底层 list
2. 重写 retainAll(Collection)、removeAll(Collection)：同样模式
3. 修复 BaseTimeBufferConsumerCollection：限制线程池大小或使用有界队列

**涉及文件**：
- `common/collection/ReadWriteArrayList.java`
- `collection/base/BaseTimeBufferConsumerCollection.java`

---

### Module 2：collection/support/ — TreeHelper 核心修复

**问题**：
- P0：6 个方法（map/filter/merge/subtract/add/intersect）抛出 UnsupportedOperationException

**修复方案**：
1. 评估各方法实现可行性：
   - map：需要 ID 重映射，复杂度高，建议标记 @Deprecated 或抛明确异常
   - filter：可实现，需处理子节点 orphaned 问题
   - merge/subtract/add/intersect：集合运算，可基于现有数据结构实现
2. 决策：实现 filter（最实用），其他方法标记 @Deprecated + 文档说明

**涉及文件**：
- `collection/support/TreeHelper.java`

---

### Module 3：cache/ — SimpleCacheHelper 功能完善

**问题**：
- P1：过期机制完全缺失
- P2：缺少批量操作（getAll/putAll）、null 值处理

**修复方案**：
1. 新增过期淘汰逻辑：
   - 在 get/set 操作时检查 expiredTime
   - 提供带 expireTime 的 set 重载
   - 驱逐时移除 expired entries
2. 新增批量操作：getAll(keys)、putAll(map)
3. null key 防御：get(null) 返回 null 而非抛异常

**涉及文件**：
- `cache/SimpleCacheHelper.java`
- `cache/base/CacheEntry.java`
- `cache/base/CacheVO.java`

---

### Module 4：collection/ — MapUtils & CollectionUtils 功能完善

**问题**：
- P1：MapUtils assert 用法（发布环境失效）
- P1：缺少常用 Map 方法（putIfAbsent/computeIfAbsent）
- P1：CollectionUtils isEmpty guard 缺失
- P1：CollectionUtils.join 缺少 distinct 重载
- P2：TreeUtils.getTreeList O(n²) 性能隐患

**修复方案**：
1. MapUtils.newHashMap：assert → IllegalArgumentException
2. MapUtils：新增 putIfAbsent、computeIfAbsent 工具方法
3. CollectionUtils：补充 isEmpty/null 检查 guard
4. CollectionUtils.join：新增 distinct 重载
5. TreeUtils.getTreeList：性能评估（待单元测试确认）

**涉及文件**：
- `collection/MapUtils.java`
- `collection/CollectionUtils.java`
- `collection/TreeUtils.java`

---

### Module 5：规范与注释修复

**问题**：
- P3：注释包含 HTML 标签（`<p>` 等）
- P3：多个方法缺少 Javadoc
- P3：author 标签使用 huitoukest

**修复方案**：

## 四、实体关系图

### ReadWriteArrayList 内部结构

```
ReadWriteArrayList<E>
├── ReadWriteLock rwLock
├── List<E> list (ArrayList)
└── modCount (继承 AbstractList)

方法重写关系：
removeIf(Predicate) ──→ 直接操作 list（写锁保护）
retainAll(Collection) ──→ 同上
removeAll(Collection) ──→ 同上
iterator() ──→ new ArrayList<>(list).iterator()（保持不变，快照语义）
```

### TreeHelper 内部结构

```
TreeHelper<T, ID>
├── List<T> allNodes (不可变拷贝)
├── Map<ID, T> nodeIndex (只读索引)
├── Map<ID, ID> parentIndex (只读索引)
├── Map<ID, List<ID>> childrenIndex (只读索引)
├── List<ID> rootIds (不可变列表)
├── Function<T, T> copier
└── Function<T, ID> idGetter

操作语义：
filter → 返回新的 TreeHelper（所有索引重建）
map → 抛出 UnsupportedOperationException（ID 重映射复杂）
merge/subtract/add/intersect → 抛出 UnsupportedOperationException
```

### SimpleCacheHelper 内部结构

```
SimpleCacheHelper<K, V>
├── int maxSize (final)
├── int currentSize
├── Map<K, SimpleCacheMember<V>> map
├── TreeMap<Integer, LinkedList<SimpleCacheMember<V>>> weightIndex
├── long globalBase
└── ReadWriteLock readWriteLock

SimpleCacheMember<V>
├── int weight
└── V value

过期机制（新增）：
├── expireTime 字段（已有）
└── 驱逐时检查 expiredTime（新增逻辑）
```

## 五、状态转换表

### ReadWriteArrayList.removeIf()

```
原始行为（错误）：
  iterator() 返回快照副本 → removeIf() 操作副本 → 底层 list 未修改

修复后行为：
  removeIf(Predicate) 直接在写锁下遍历 this.list
  → 正确修改底层列表
  → modCount++ 正确更新
```

### SimpleCacheHelper 过期机制

```
新增过期逻辑：
  get(key) → 检查 expiredTime → 已过期 → remove(key) → 返回 null
  set(key, value, expireTime) → 存储 expireTime
  evict() → 检查 expiredTime → 已过期 → 跳过不计入 currentSize
```

## 六、核心边界条件与异常处理

### 边界条件

| 场景 | 处理方式 |
|------|----------|
| ReadWriteArrayList.removeIf 匹配全部 | 写锁下逐个移除，modCount 正确更新 |
| ReadWriteArrayList.removeIf 空列表 | 无操作返回 false |
| TreeHelper.filter 过滤后无根节点 | 允许空树，返回空索引 |
| SimpleCacheHelper.get 已过期 entry | 驱逐并返回 null |
| SimpleCacheHelper.set null key | 防御：直接返回，不存储 |
| MapUtils.newHashMap size mismatch | IllegalArgumentException（替代 assert） |

### 异常处理策略

| 方法 | 边界条件 | 异常类型 | 处理方式 |
|------|----------|----------|----------|
| newHashMap | keys/values size 不一致 | IllegalArgumentException | 明确异常替代 assert |
| TreeHelper 未实现方法 | 调用 map/merge 等 | UnsupportedOperationException | 保持，明确注释 |
| BaseTimeBufferConsumerCollection | checkInterval ≤ 0 | IllegalArgumentException | 构造函数校验 |

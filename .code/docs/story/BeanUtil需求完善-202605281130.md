### 1.2 未迁移方法分析

#### 方法5 & 12：Predicate/Function 风格拷贝

```java
// 方法5 (line 155)
public static <T> void copyProperties(Object target, Object source, 
    Predicate<Tuple2<Field, Object>> predicate, 
    Function<Tuple2<Field, Object>, Object> mapper, 
    String... exceptFields)

// 方法12 (line 373)
public static void copyProperties(Object target, Object source, 
    Predicate<Tuple2<String, Object>> predicate, 
    Function<Tuple2<String, Object>, Object> mapper, 
    Collection<String> exceptFields)
```

**问题**：
- API复杂，泛型不一致（Field vs String）
- 与新的 CopyOptions 设计不兼容
- 没有对应的 CopyOptions 等效实现

**建议**：
- 方案A：**不迁移**，直接删除（API复杂，使用频率低）
- 方案B：**保留在BeanUtils中标记@Deprecated**，不迁移到BeanUtil
- 方案C：**新增 CopyOptions 支持编辑器的等效功能**

## 问题3：静默处理行为确认

### 3.1 代码验证

**BeanCopier.copy() 第105-120行**：
```java
if (value != null && value.getClass() != targetType && useConverter) {
    try {
        Object convertedValue = ConverterRegistry.getInstance()
                .convert(value, (Class<Object>) targetType, value);
        value = convertedValue;
    } catch (Exception e) {
        // 转换失败 → 跳过该属性，debug日志记录
        if (logger.isDebugEnabled()) {
            logger.debug("Property conversion failed: " + propName + ", skipping", e);
        }
        continue;
    }
}
```

### 3.2 行为总结

| 场景 | 行为 | 是否符合预期 |
|------|------|-------------|

| 有Converter，转换失败 | 跳过该属性，debug日志 | ✅ 静默 |
| 无Converter，类型不匹配 | 跳过该属性，debug日志 | ✅ 静默 |
| 无Converter，类型匹配 | 正常赋值 | ✅ |

**结论**：✅ **静默处理行为符合预期**

## 核心场景（第2期）

### 场景7：忽略大小写的属性拷贝

```java
// Hutool风格
BeanUtil.copyProperties(source, target, true); // ignoreCase=true

// CopyOptions风格（建议）
CopyOptions options = CopyOptions.create().setIgnoreCase(true);
BeanUtil.copyProperties(source, target, options);
```

**验收标准**：
- [ ] 字段名大小写不敏感匹配
- [ ] "userName" → "username" 能匹配
- [ ] "UserName" → "userName" 能匹配

---

### 场景8：忽略转换错误的Bean填充

```java
// 部分字段类型不匹配时，返回已填充的字段
User user = BeanUtil.toBeanIgnoreError(map, User.class);
```

**验收标准**：
- [ ] 部分字段转换失败不影响其他字段
- [ ] 返回已填充的Bean（而非抛异常）
- [ ] 可以通过某种方式获知哪些字段失败了

---

### 场景9：判断Bean是否为空

```java
// 判断Bean所有属性都为null
boolean empty = BeanUtil.isEmpty(user);

// 判断Bean包含null属性
boolean hasNull = BeanUtil.hasNullField(user);
```

**验收标准**：
- [ ] isEmpty正确判断所有属性为null
- [ ] hasNullField正确检测包含null属性
- [ ] static字段不参与判断

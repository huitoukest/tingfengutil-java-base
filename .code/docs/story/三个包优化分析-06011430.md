### 1.2 缺陷问题（已验证）

#### P0 - 严重缺陷

**已移除的错误标记**：
- ~~SimpleCacheHelper.evict() 方法存在严重 bug~~ → 代码审查确认：第 255 行 `map.values().remove(toEvict)` 是**有意为之的设计权衡**，代码注释明确说明"由于 currentSize 远大于平均每个 weight 的 entry 数，此处 O(n) 可接受。如需 O(1)，需在 SimpleCacheMember 中保存 key 引用"。由于 `SimpleCacheMember` 未重写 `equals()`（只重写了 `getWeight/setWeight/getValue/setValue`），HashMap 的按值删除只会精确匹配那一个对象。此条标记为 bug 是误判，特此移除。
